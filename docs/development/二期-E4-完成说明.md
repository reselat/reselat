## 数据语义与限制

时间线耗时由 run.started_at／前一步 created_at 到当前 created_at 计算，包含等待、重试和暂停；不是独立测量的业务工具或模型耗时。时间缺失、非法或负间隔显示未知；旧数据无需迁移。

当前编排无关联到 run 的模型调用记录，API 使用 `source: placeholder` 返回零调用、零 token、零估算费用。页面明确标注占位，不能当作真实账单。未把公司/日期级其他 AI 调用费用分摊到 run。非零汇总仅在测试夹具验证，后续接入需持久化可信 run 归属记录。

Node Host / Next 从项目根目录运行；独立打包部署须保留追踪的 skills/trade 资源。无数据库 schema 变更。

## 安全边界

四步仍结束于 `awaiting_approval`。Agent 没有自批、发送或恢复成功权限。MCP 仍不提供 `plan_confirm`、`run_claim`、`pipeline_advance`、`run_resume`、`outreach_approve`、`outreach_reject`、`outreach_send`。详情保持管理员授权和 company_id 隔离。

未连接远程或生产库，未调用 SMTP、发送工具或真实模型计费；数据库测试使用本机临时 PGlite。只读取 `~/.codex/refs/EvoFlow/README.md` 了解技能、过程可观测和用量心智，未读取或复制 EvoFlow 实现源码、技能内容。
