## 回滚（人工、维护窗口）

先停 Host 并备份数据。以下按 10→1 逆序执行，每段包在 BEGIN/COMMIT 中；禁止 CASCADE。已有业务数据应优先前滚修复，回滚会删除二期数据。

人工核对点：以下 SQL 仅适用于原迁移未被修改的结构；先对照上面的 catalog 快照核定约束名。第 5 段遇到新状态、第 3 段遇到已批准/拒绝记录会失败并回滚该事务，不得自动降级或删除记录，应前滚。第 2、1 段仅在人工确认无业务依赖且数据已导出时执行。客户与跟进回写保留，需人工依据审计对账。

## Host 常驻

Host 不上云（不部署于 Cloudflare / Vercel）。小型 VPS 使用专用非 root 用户，systemd 配置 WorkingDirectory 为发布目录，ExecStart=/usr/bin/node scripts/agents/agent-host.mjs，Restart=on-failure，EnvironmentFile 指向仅该用户可读的本机文件。设置 NoNewPrivileges=true；日志进入 journal。发布前先停服务，发布后检查日志及人工门禁，再启用 pipeline。

环境变量仅列名称：AGENT_BUSINESS_ORIGIN、AGENT_COMPANY_ID、AGENT_SESSION_COOKIE、AGENT_INTERVAL_MS、AGENT_STOP、AGENT_STOP_FILE。会话过期需人工更新；不得把会话写入版本库或日志。服务端数据库环境配置由人工依据既有部署规范维护，不向 Host 发放数据库直连权限。

急停：在指定 AGENT_STOP_FILE 路径 touch 文件；或设 AGENT_STOP=1 后重启；必要时 systemctl stop。急停在命令边界生效，在途事务需检查审计。租约过期后人工 run_requeue，再恢复 Host；不要直接改状态。取消 run 后不得 advance。恢复前先确认审批队列和回写是否已完成。
