## 手动验收

1. 重启 `npm run test:local`，访问 http://127.0.0.1:3120/login，选择测试管理员。
2. 从设置进入任务中心，创建 pipeline，使用 example.test 邮箱填写 name/email/subject/body 并加入队列。
3. 点击 run ID 查看状态、租约和步骤，点击刷新观察。可用急停取消任务；补跑仅适用于失败或租约过期任务。
4. 切换 sales / operations，确认导航不展示任务中心，直接访问被管理员权限校验拒绝。
5. 本任务不启动 Agent Host。未启动 Host 时 queued 无步骤属于正常现象；人工审批仍需既有会话闸门，本页不提供批准操作。
