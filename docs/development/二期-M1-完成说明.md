## 同页流水线

顶部五节点使用原生锚点链接，键盘可达，目标可聚焦；当前节点使用 `aria-current="step"`。

| 当前所选线索状态 | 高亮步骤 / 定位 |
| --- | --- |
| 无选择 | 发现 / 搜客，定位线索清单、新增、JSON 导入 |
| 有选择，无背调和草稿 | 筛选 / 背调 |
| 有背调，无草稿，或最新草稿 draft / rejected | 定制开发信 |
| 最新草稿 pending | 人工审批 |
| 最新草稿 approved | 回写占位，提示已通过待通道 |

草稿按现有 API 的倒序取当前线索最新版本，步骤不依赖审批队列筛选。左侧线索、右侧背调与草稿，审批队列位于下方；窄屏改为单栏。未选择线索时也保留背调、草稿定位提示。回写占位说明通道未接入，保留 E6 的实际客户与跟进回写操作，不宣称邮件已发送。

复用 E6：`leads_upsert`、`diligence_save_report`、`outreach_draft_email`、`outreach_submit_approval`、人工 `outreach_approve` / `outreach_reject`、`outreach_writeback` 及原 list views；未改服务端、数据库、MCP。非管理员的资源 hooks 同时禁用请求。
