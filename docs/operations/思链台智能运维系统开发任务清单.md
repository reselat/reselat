# 思链台智能运维系统开发任务清单

依赖《思链台智能运维系统设计》。执行这些任务需建立独立项目、明确平台权限/数据外发/预算；本清单不代表已创建仓库、开通服务或安装Eve。首个接入对象为思链台云端验收环境。

## O1：只读控制台

1. 初始化独立Web/API及Eve运行时技术探针，固定版本，验证生产登录策略、一个真实受限Agent turn、受控模型连接；不使用placeholder认证上线。
2. 建立运维用户、项目、环境、资源绑定与凭据引用，提供只读/operator/approver/owner权限测试。
3. GitHub App绑定指定仓库，显示branch、完整SHA、CI与线上部署分别的版本；初始不给仓库写权限。
4. HTTP探针支持预期状态矩阵：健康200、受保护API未登录401；界面显示数据新鲜度与缺失。
5. 独立证据库保存结构化结果和摘要，模型不可用仍能检查和出报告。
6. Vercel部署/日志和Supabase只读状态连接均按实际权限测试；不能通过.env.example或空日志推断配置已就绪。

验收：真实手动只读巡检一轮；无任何生产写调用；连接403/过期/限流显示为未知或工具失败，不显示健康。

## O2：调度与多Agent

7. 持久任务、唯一触发、租约及heartbeat，显式区分at-least-once投递和幂等副作用；测试进程崩溃和恢复。
8. UI创建/停用计划，时区Asia/Shanghai、3次下次运行预览、维护窗口、漏跑/重试/超时与预算。
9. 首批协调、可用性、安全、回归、修复、复核6角色；3个分析子任务并发，依赖边明确；每个模型只有角色需要的工具。
10. 全局急停、撤权与任务取消，过期lease/fencing token拒绝写；费用按run/step/模型累计。
11. 在真实生产调度runner验证触发，不能用Eve dev手动dispatch冒充定时已运行；定时器只创建任务，不在无交互会话中等审批。

验收：同触发重复投递、多worker竞争、重启、预算耗尽、停止/撤权和时区转换均通过。

## O3：GitHub隔离检查

12. 固定SHA下载器与无凭据执行沙箱，工具镜像和锁文件版本可追溯；GitHub拉取令牌不进入测试环境。
13. 现有CI协议采集，并支持可复现的本地/远端扫描任务；保留原退出码、输出hash与覆盖。
14. 选择和锁定依赖、静态、密钥扫描工具及规则版本；按许可证/仓库权限决定是否启用CodeQL/Code scanning，不默认收费能力。
15. 加入恶意README/PR注入、恶意构建脚本、外连窃取、资源耗尽和输出超量测试。
16. 输出candidate/validated/false_positive和infra_error等独立状态；缺件、unsupported或工具失效不能形成扫描通过。

验收：在无生产秘密沙箱运行完整测试与首批扫描；验证已知缺陷、已知正常业务校验和工具失败三种情况。

## O4：修复协作

17. 修复Agent独立分支/工作区，只改任务允许路径；并发冲突进入合并队列。
18. 通过独立复核及回归后生成精确变更包；记录代码/环境/策略指纹、有效期、验证和恢复前提。
19. 仅在授权后由GitHub写适配器创建草稿PR；Agent不能批准自己的方案或扩大写权限。
20. 新SHA/新部署/schema或策略漂移后审批失效；PR接口超时后先查询已创建状态，避免重复。

验收：端到端“一条验证缺陷→隔离补丁→复测→人工批准→草稿PR”，不合并或发布。

## O5：受控运维执行

21. Runbook白名单、审批包hash与当前目标重验、单环境写租约，执行器凭据与模型隔离。
22. 首个发布runbook先在测试环境验收；执行READY、精确SHA/产物、读取/文件链路和观测窗口验证。
23. 回退runbook验证schema/配置兼容；写调用未知结果进入needs_reconciliation，禁止盲重复。
24. 审计、控制面备份恢复、任务恢复、报告与通知intent；通知渠道经指定授权后才真正发送。

验收：测试环境发布与回退演练、批准后漂移、半途撤权、未知结果对账、异机恢复，以及控制面自身故障后的恢复。全部通过后再评估生产自动化级别。
