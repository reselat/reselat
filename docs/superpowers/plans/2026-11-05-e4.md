# E4 技能与观测 Implementation Plan

> 执行方式：按用户 E4 简报在当前隔离 worktree 内直接执行。

**Goal:** 白名单外贸技能、只读步骤时间线与 run 用量占位，保持人工审批。
**Architecture:** Node Host/MCP 共用固定技能目录加载器；服务端 runGet 派生观测 DTO，不变更编排写路径。
**Tech Stack:** Node ESM、TypeScript、React、Vitest、PGlite。
**Spec:** docs/development/二期-E4-任务简报.md

## Global Constraints

MCP 不增加人工或 Host 专用命令。最终仍停 awaiting_approval。
