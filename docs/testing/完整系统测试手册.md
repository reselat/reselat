# 完整共享系统测试手册

测试入口：https://trade-workstation-test.vercel.app/workspace 。管理员在同一工作台往返“成员与角色管理”；身份账号与业务资料分别保存在两个Supabase项目。请使用虚构资料验收，`/demo`仍是隔离的浏览器本机试用区。

## 准备与角色

管理员完成登录及MFA，检查公司设置的商业抬头、地址和收款资料。业务员负责自己的客户、跟进与销售草稿；运营只有被指派订单的采购、到货和出运权限。共享客户是只读访问；供应商全库和采购默认值仅管理员可维护。管理员先在订单采购页签授权可用供应商，再由运营采购。

自动验收临时员工带 `SYNTHETIC E2E` 前缀，结束后停用；测试资料保留。原员工不改。不应将测试公司/税号/签名图片用于真实业务。

## 客户、产品与销售

1. 客户页新建客户并选择来源；进入“跟进/访问”记录本次与下次跟进日期，首页到期提醒应能定位客户。管理员可共享、撤销共享，或先预览再确认移交。
2. 管理员维护供应商和产品，填写商品编码、申报要素、来源、日期及人工核验信息。运营编辑产品时保持待核验且看不到默认采购成本。非空中英文/SKU搜索应返回正确资料。
3. 业务员在销售订单页新建，选客户和商品、数量、销售价、币种、贸易地点、付款/交货条件。商品带入默认销售价，仍允许本次议价；合计由服务器精确计算。
4. 业务员提交，管理员确认并指派运营。确认后公司、客户、商品与销售条件形成冻结来源版本；改主档不回写历史单据。旧页面版本保存应提示刷新。

## 采购、到货与分批出运

1. 管理员在确认订单中授权供应商；运营按供应商和币种建立采购单，可分多次、多供应商。累计采购不得超过销售量。
2. 运营提交、管理员确认采购；运营录入分次到货，不能超采购量。采购页同时显示已到货数量。
3. 出运装箱页按具体到货来源分配数量，填写箱数、重量、体积、唛头、尺寸、装卸港。可用量为已到数量扣除有效确认出运，不把草稿当作已出运。
4. 管理员确认批次，累计销售/到货量均不能超限。多批金额累加应等于销售行总额，保留四位数量/单价及最小货币单位金额。
5. 取消确认批次需管理员、原因、先作废相关正式CI/PL，且按逆序取消。已完成订单需先显式重新打开。取消/重复请求不可二次释放。

## 收付款与完成

业务员登记销售收款；管理员确认后才计入已收，采购付款由管理员登记/确认。币种必须相同，金额不能超未结余额，凭证号不能重复；冲销保留原流水与原因。首页分币种显示余额，不做汇率折算。全部确认出运、销售收款、采购结清且无待确认收付款后才允许完成订单。

## 单据、签名与附件

PI/SC从销售确认版本创建；PO从确认采购创建；CI/PL从确认出运创建。先预览草稿，再由管理员确认并生成固定PDF。运营须有具体签名图片/用途授权才能确认正式单据。更正先作废原件，再创建关联原件的新单据；作废件只能通过标明作废历史的入口下载，文件名带VOID，原字节保留。

签名素材由管理员上传PNG/JPEG（2MiB），按员工和单据类型授权。确认时再次核验授权版本；确认后PDF绑定固定图像摘要。页面“已加盖图片”不代表客户已签署；客户回签件单独作为附件上传。

附件支持PDF/PNG/JPEG（10MiB），走2MiB分片。上传中断保留原文件重试或核对；不会覆盖已归档对象。采购敏感凭证不向业务员开放，签名原图不能通过通用附件接口下载。

## 退税资料

七类清单按实际文件整理；管理员复核或说明不适用。缺文件、未复核HS、出运数量不一致、缺CI/PL或冻结归类已经过期时，检查报告保持待补齐/草稿。可导出CSV、检查PDF和ZIP；ZIP含目录、检查表、摘要清单及逐文件核验后的原件。可减少所选文件，部分导出始终标为草稿。

源文件总量50MiB、ZIP最多100项（其中固定3项）；最终导出文件也不得超过50MiB。超过时减少所选文件。所有文件私有，下载时重新核验权限与摘要。不伪造税务/报关凭证，不自动判断退税资格或申报。

## 失败与恢复

- 版本冲突：刷新后核对新版本，再决定是否重填。
- 提交结果未知：保留原内容，点击“核对上次提交”；系统重用请求ID，不能重新建同一笔业务。
- PDF/ZIP归档中断：点击生成/核对；只有确认对象不存在且重建摘要相同时才同路径补传，不覆盖已有对象。
- 正式来源仍被单据锁定：先在单据中心作废相关正式件再修改来源，保留历史。
- 账号停用后：新请求应拒绝；已在跨库处理的请求存在已说明的在途窗口，不将其描述为瞬时撤回。

## 验证范围与运行维护

本地SQL、精确金额、权限、重复投递、失败恢复、PDF字节、ZIP及虚构联合恢复已覆盖自动化测试；本地数据库使用PGlite，Auth/Storage适配器模拟。线上验收另记于聚合证据文件，未执行的真实流量/多人长时间并发不声称通过。

数据库与Storage应联合备份：数据库业务表/冻结版本/对象路径、文件原件及SHA256清单必须对应同一验收时间点；恢复到隔离测试环境后按文件摘要和授权下载逐项核验。当前已做虚构PGlite数据目录＋模拟私有对象的本地恢复，不将其冒充Supabase网络备份演练；真实业务导出/备份需要独立授权。

## 2026-10-25 客户合同与开票公司资料

1. 在客户管理中新建/编辑客户，分别填写基础、合同主体和客户开票资料；列表的“公司 / 开票资料”可只读查看，银行账号按文本保留前导零。
2. 合同全称/注册地址和开票抬头/地址可不同；留空时沿用基础资料。PI/CI为商业单据，不是自动开具的税务发票。客户开户行与账号不作为我方收款账户。
3. 新订单确认会冻结当时客户资料；生成SC核对合同主体、注册号和授权签署人，生成PI/CI核对开票抬头与税号。修改客户档案不回写已确认历史单据。
4. 我方公司资料在财务管理，仅管理员维护；客户公司资料在客户管理。操作记录（含订单内页签及接口）仅管理员查看，销售和运营不提供此入口。

## 2026-10-25 CO、样品单与商品行

1. 产品/供应商新建保存后进入CO维护，也可在列表点“原产地证书（CO）”。上传PDF/PNG/JPEG（单件最大10MiB），等待归档并关联；每个主档最多关联10份。移除关联保留旧文件和历史订单。
2. 客户/供应商编辑中可设置“业务参考号”。新建销售订单会从客户自动取值，采购及PO会从供应商自动取值，无须在销售建单时手填客户参考号。
3. 新建订单选择“正常订单”或“样品单”；蓝/紫圆点同时带文字。选择商品自动带出HS Code，数量/单价/行金额与HS一排对齐（窄屏两列），金额仍按实际数量单价计算。
4. 订单保存/确认固定当时产品及默认供应商CO，采购保存固定实际供应商CO。在订单“合同与单据”的“产品原产地证书（CO）”下载；这是来源证书，需核对批次适用性。主档换证不覆盖已确认历史。
5. 旧订单可能未包含CO。未确认草稿可在补齐主档后重新保存或确认；已确认订单若需换来源应走受控变更流程，不能静默修改历史。销售不能裸读主档CO，只可下载有权订单关联的文件。

## 出运与系统主题补充

- 出运前先确认采购并录入实际到货。在出运表单填写“到货来源”的本次出运数量，再填本批次箱数、总重量及总体积；仅填箱数/尺寸不能代替出运数量。没有可用到货时页面给出采购入口并禁用保存。
- 净重、体积必须大于0，毛重不得小于净重。单箱尺寸按厘米且每箱一致时，可点击尺寸计算按钮换算总CBM；30×30×30cm、1箱=0.0270m³。
- 右下角“跟随系统”会实时响应系统外观改变；选择浅色/深色后保持手动设置，刷新和跨标签记住偏好。
