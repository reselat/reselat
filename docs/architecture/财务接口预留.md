# 外部财务接口预留契约

本轮只提供业务收付款台账，外部财务集成保持disabled。`integration_outbox`不向business_backend授权，不启动worker，不发送第三方数据。没有可用的财务同步按钮或已接通声明。

未来经独立审核的服务端适配器可消费明确事件：payment.confirmed、payment.voided；字段为companyId、eventId、paymentId、orderId、purchaseId?、kind（sale/purchase）、currency、amountMinor（整数字符串）、businessDate、reference、reversalOf?、version、occurredAt。凭证正文/个人信息不进入普通日志。币种不换算，amountMinor按当前currencyScale解析。

鉴权应为服务端独立凭证与最小租户范围，不复用用户Cookie或Supabase管理密钥。发送前按(companyId,eventId,target)预留并持久化幂等键，接收端同键同载荷返回原外部ID、异载荷拒绝。冲销追加反向事件并引用原事件，不删除已记账记录。超时为结果未知，保留预留和原始回执，先对账核验，不能用自动重复发送假装成功。

对账按币种比较有效确认金额、冲销金额、外部ID和事件状态；不以发送成功代表入账成功。第三方API、费用、脱敏、重试上限与启用/停用范围未批准前，本契约不激活任何外部调用。

2026-10-25：版本化TypeScript端口与严格事件schema见 `src/server/integrations/contracts.ts`。新增AI任务契约仅用于二期边界，未启用外发。完整本地化与集成路线见《思链台本地化与二期扩展方案》。
