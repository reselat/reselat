# 首轮权限契约与已实现边界

授权核心已获本次本地实施批准；真实身份和数据库策略尚未接入。

## 已实现纯授权

所有角色先校验身份存在、enabled、companyId。管理员只能在本公司范围操作。sales 可读写本人或明确共享客户／订单，不可 cost.read 或 settings.write。operations 仅允许授权范围 order.read；其他运营动作将随采购／出运命令逐项加入，默认拒绝。

成本查看当前只允许 admin。后续采购成本委派须显式扩充能力字段和拒绝测试，不通过角色名称自动放大权限。

projectOrder 返回允许字段白名单；业务员返回对象不存在 purchaseCostMinor。测试直接检查返回值，不只检查页面。

## 尚未实现

Supabase JWT 验证、管理员 MFA、账号邀请／停用会话、数据库 GRANT／RLS、文件签名授权和端到端员工数据范围。业务 API 直接拒绝未配置状态，不能将纯规则测试称为登录权限集成通过。

## 发布前最低检查

不同公司管理员、停用用户、共享撤回、伪造角色、任意资源 ID、字段投影、导出和文件路径分别有拒绝测试；不将可编辑 user_metadata 用于授权。服务端与日志不暴露高权限密钥。
