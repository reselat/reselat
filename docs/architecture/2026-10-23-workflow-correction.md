# 录入、单据与财务闭环修订

用户指出首轮缺失录入生成单据、新建订单、欠款提醒、财务和退税资料。本轮属于已批准整体方案的本地功能补齐，不开云环境，不改真实身份边界，不新增依赖。

## 实施切片

1. 可测试业务模型：客户、产品、公司、销售、采购、出运、收付款、单据快照、资料清单；金额 BigInt 最小单位，币种分别汇总。
2. 本机浏览器持久存储与实际表单，刷新后保留。不是共享数据库，不用于真实敏感资料，不承诺多员工并发。
3. 新建订单从维护的客户／产品选择；可显式按供应商生成采购；快照固定描述、地址和价格。
4. 财务展示销售应收、实收、未收、到期未收，采购应付／实付；收付款仅登记，不发起转账，拒绝超额、币种不匹配和重复流水。
5. PI 来自订单、PO 来自采购、CI/PL 来自实际录入出运；采用已查询的字段布局，PDF 生成后持久保存不可变快照。
6. 退税资料页提供按订单清单与缺件提醒、文件索引及目录导出；不伪造凭证、不自动申报、不以打勾代表财务复核完成。

## 样式与字段依据（2026-10-23 查询）

- UNECE Recommendation 1 / UN Layout Key：https://unece.org/trade/uncefact/tf_recommendations ，参考对齐式贸易表格布局，不宣称取得认证。
- PI：https://www.trade.gov/pro-forma-invoice ，卖方买方、编号参考、品名、单位价格、金额、付款／贸易条件、日期。
- CI：https://www.trade.gov/commercial-invoice ，目的国可能有额外格式要求；不将美国特定声明套入中国出口。
- PL：https://www.trade.gov/common-export-documents ，出运、包装、数量、净毛重和唛头；不以装箱单替代商业发票。
- DHL：https://www.dhl.com/discover/zh-cn/ship-with-dhl/export-with-dhl/special-case-documents-for-export ，发票与运单及装箱数据一致。
- 税务管理解读：https://shanghai.chinatax.gov.cn/zcfw/zcjd/202602/t479289.html ，资料清单由财务确认。网页读取成功；UNECE PDF 正文403，仅采用其官方页面说明。

## 验证

先写模型测试并见红；再实现；PDF 做实际文本与画面检查；浏览器走录入→订单→收款→首页提醒→出运→生成／下载→刷新保留。期末独立只读复核。真实数据库／认证／并发和正式税务申报仍未覆盖。
