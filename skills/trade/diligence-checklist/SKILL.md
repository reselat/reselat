# 背调清单
核对公司名称、域名、经营范围、联系人与公开渠道的一致性。
为每项结论记录来源、观察日期和支持证据；区分事实、推断与缺失信息。
不能核实时写明未知，不以缺少负面记录证明安全。未提供摘要时明确提示人工核查。
仅保存当前公司的背调报告，后续草稿与审批由对应岗位和人工处理。

## 公开渠道「有没有」与「活不活」
- 分别核对官网与社媒是否存在（有没有），再核对最近可证更新（活不活）。可访问、有账号或本次抓取成功不能证明近期更新。
- 使用 `website_last_update`、`social_last_update` 声明最近可证更新，每项附 `observed_at`（ISO 日期 `YYYY-MM-DD`）与 `sources`（引用证据 ID）；日期必须对应可证更新，不能用本次查询日期替代。
- 官网更新日距融合当日 ≤ 180 天、社媒 ≤ 90 天；按 UTC 日历日计算，包含边界日。社媒可用 `social_last_update:<平台>` 分别声明；任一平台有在窗证据即可提供社媒活跃信号。
- 确认无官网/无社媒时可显式声明 `value: absent`，并保留核查来源。缺渠道、超窗、缺日期、缺来源、未来日期或未知不能证明不活跃，更不能因此淘汰或判定不是潜在客户。
- 官网与社媒双有且有来源、在窗时输出 `activity_tier=strong`，其他条件达标时允许高置信并倾向潜在客户；其余为 `activity_tier=unknown`，摘要标注「活跃度未知，建议人工补证」，置信度降级，但默认不单独阻断 `auto_accepted`。
- 活跃度不参与业务一致率的负向投票；独立审计席、一致率、敏感声明来源及其他阻断规则继续执行。强活跃不覆盖这些规则，Agent 不得自批。
- 继续遵守 Path A / 闸门 A、发信后置；不启用 SMTP，不做 Maps。人工决定仅通过已认证人工入口完成。
