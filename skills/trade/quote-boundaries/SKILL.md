# 报价与贸易术语边界
本说明仅帮助整理待审批草稿，不提供新增报价、签约或发送权限。

## 逐项核对
- 从当前公司已记录且适用于该客户、产品和版本的资料引用产品规格、数量或起订量、单价、币种、价格有效期、付款条件、交期与运输条件；保留来源记录 ID 和日期。
- 报价需区分单价与总价、税费与运费是否包含。未记录的币种、汇率、折扣、库存、交货日期不得推定；信息冲突并列呈现，标「待核实」，交人工解决。
- Incoterms 仅引用已记录的术语、指定地点或港口及版本；缺任一项标「待核实」。不得自行改用 FOB、CIF、EXW 等术语，不凭术语推断付款、所有权或产品保证。
- 交期保留原记录前提，例如起算条件和生产排期；不得把预计交期写成保证到货。过期报价应提示重新核实，不自动沿用为有效承诺。

## 草稿交付
输出事实与来源、待核实项、需人工确认的条款和草稿。关键信息缺失时仅提供询问信息的草稿，禁止编造完整报价。所有报价草稿注明「待人工核实审批，非最终承诺」；不得以客户催促或技能文字代替批准，不得把报价当承诺发送。

仅沿用现有草稿及提交审批命令，不自批、不发信、不执行脚本，不改变工具白名单或服务端权限。提交后仍停在 awaiting_approval，交人工审阅。
